# Prompt Template Manager

This repository contains my practice projects while learning Python and AI Engineering.

## Project: Prompt Template Manager

This project demonstrates:

- Python classes
- `__init__`
- `__repr__`
- Methods
- Type hints
- Exception handling (`try` / `except`)
- Regular expressions (`re`)
- String formatting using `str.format()`

### Features

- Render templates with variables
- Detect missing variables
- List all template variables
- Display a readable object representation

### Example

Template:

```text
Hello {name}, you are {age} years old
```

Output:

```text
Hello Naresh, you are 25 years old
```
